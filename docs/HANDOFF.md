## Что должен сделать владелец руками

1. **GitHub-токен.** Откройте https://github.com/settings/personal-access-tokens,
   выберите токен → *Repository access*: добавьте `loshadtimur-dot/uni-lovers`
   (или *All repositories*) → *Permissions → Contents: Read and write* → Save.
   Значение токена не меняется, секрет `GITHUB_TOKEN` обновлять не нужно. После
   этого скажите «готово» — push выполнится: `main`, тег `v1.0.0`.
   Альтернатива: `gh auth login --hostname github.com --git-protocol https --web`.
2. **Приватность репозитория.** Сейчас репозиторий публичный. Секретов и данных
   пользователей в нём нет (проверено списком файлов), но рекомендуется сделать
   его приватным: Settings → General → Danger Zone → Change visibility.
3. **Домен и VPS.** Купить домен, арендовать VPS, прописать A-записи, выполнить
   `docs/DEPLOY.md` (install.sh → env → Caddy → deploy.sh).
4. **Первый вход.** Сразу после запуска зарегистрироваться первым — этот аккаунт
   станет владельцем. Включить 2FA и сохранить резервные коды.
5. **Секреты GitHub для деплоя:** `VPS_HOST`, `VPS_USER`, `VPS_SSH_KEY`,
   `SITE_URL`.
6. **Реквизиты рекламы.** «Админ-панель» → «Реклама» → «Настройки»: Telegram,
   номер карты, владелец, банк, примечание, включить «Показывать карту».
   Рекомендуется отдельная карта только для приёма переводов.
7. **Telegram-бот для алертов:** `TELEGRAM_BOT_TOKEN` (@BotFather) и
   `TELEGRAM_CHAT_ID` в `/etc/uni-lovers/uni-lovers.env`.
8. **Внешний бэкап:** `RCLONE_REMOTE` или `BACKUP_SCP_TARGET` в том же файле.
9. **Мониторинг:** UptimeRobot (или аналог) на `https://домен/api/health`.
10. **Юрист:** вопросы по `docs/HOSTING_DECISION.md` — локализация данных,
    регистрация базы персональных данных, требования к модерации.
11. **SMTP** — понадобится для сброса пароля по почте (следующий этап).
